# Новое в PHP 8.6

[Обзор релиза PHP 8.6](https://www.php.net/releases/8.6/en.php)

## Частичное применение и границы диапазона

Выражение `$limit = clamp(?, 1, 50);` создаёт замыкание с фиксированными границами. Вызов `$limit(80)` подставляет аргумент вместо `?` и возвращает `50`. Сравнивать можно и объекты `Time\Duration`: так удобно ограничить время ожидания перед повторным запросом.

## Направление сортировки и readonly-свойства

Если метод принимает `SortDirection`, передайте ему `SortDirection::Descending` для сортировки по убыванию. Целое число в таком вызове приведёт к `TypeError`. Значение по умолчанию можно закрепить при объявлении свойства:

```php
final class SortOptions
{
    public readonly SortDirection $direction = SortDirection::Ascending;
}
```

## Потоки и сетевые запросы

Чтобы дождаться данных, зарегистрируйте дескриптор в `Io\Poll\Context` с событием `Io\Poll\Event::Read`. Метод `wait()` вернёт наблюдателей, для которых наступило событие. Обработку ошибок настраивают отдельно: режим `StreamErrorMode::Exception` позволяет получить из исключения код ошибки, имя обёртки и путь или URL.

При повторной отправке тела запроса из потока, например после перенаправления, libcurl может потребоваться перемотка. Обработчик `CURLOPT_SEEKFUNCTION` позволяет выполнить её. [Список изменений PHP 8.6.0](https://www.php.net/ChangeLog-8.php#8.6.0)

## Рефлексия параметров и свойств

Метод `ReflectionParameter::getDocComment()` возвращает документирующий комментарий, размещённый непосредственно перед параметром. Методы `ReflectionProperty::isReadable()` и `isWritable()` проверяют доступ к свойству из указанной области видимости. Например, свойство с модификаторами `public private(set)` можно прочитать извне, но записать в него значение извне нельзя.

## Что проверить перед обновлением

- Уберите `return` из `finally`: он может скрыть исключение.
- Функции `mb_ereg()` и `mb_split()` объявлены устаревшими. Перенесите регулярные выражения на PCRE. Для строк в UTF-8 используйте модификатор `u`.
- Вызовы `is_long()` и `is_integer()` замените на `is_int()`, а `doubleval()` — на `floatval()`.
- Проверяйте результат `file_put_contents()`: сбой при сбросе буфера или закрытии потока теперь приводит к возврату `false`.
- По умолчанию включены `session.use_strict_mode` и `session.cookie_httponly`, а для `session.cookie_samesite` задано значение `Lax`. Пользовательский обработчик сессий должен реализовать и `create_sid()`, и `validateId()`: отсутствие любого из этих методов считается устаревшим поведением.
