# Вопросы и ответы для собеседования по PHP

Добро пожаловать в полную коллекцию вопросов и ответов для собеседования по PHP.

## Структура

В боковом меню собраны 29 тем: от основ PHP и сессий до задач LeetCode и регулярных выражений. Для вопросов указаны уровни сложности Junior, Middle и Senior. В разделе «Ответы» можно найти подробные разборы.

## Как пользоваться

Выберите тему в боковом меню или воспользуйтесь поиском в шапке сайта. Введите название функции, текст вопроса или ключевое слово, чтобы найти материал по всей документации.
